CoreS3-Lite Air Station Setup Guide

Step-by-step PlatformIO setup, build, upload, and first-boot checks for the SEN66 air-quality station firmware.

What You Need Install PlatformIO Open The Project Build Upload Configure Wi-Fi Web Dashboard Troubleshooting

1. What You Need

  • M5Stack CoreS3-Lite.
  • Sensirion SEN66 connected to Grove Port A through the Adafruit 6331 breakout.
  • USB-C data cable. Some USB-C cables only charge and will not work for programming.
  • microSD card formatted as FAT32.
  • Windows PC with VS Code and PlatformIO.
Hardware check: Grove Port A uses SDA GPIO 2 and SCL GPIO 1. The SEN66 I2C address is 0x6B. Grove VCC is 5 V, so feed it into the Adafruit breakout input and let the breakout regulator power the SEN66 at 3.3 V.

2. Install PlatformIO

  1. Install Visual Studio Code.
  2. Open VS Code.
  3. Open the Extensions panel.
  4. Search for PlatformIO IDE.
  5. Install the official PlatformIO extension.
  6. Restart VS Code if it asks.

Check PlatformIO From PowerShell

Open a new PowerShell terminal and run:

pio --version
Expected: You should see something like PlatformIO Core, version 6.1.19. A newer version is usually fine.
If PowerShell says pio is not recognized: close and reopen VS Code, then try again from the VS Code terminal. If it still fails, open the PlatformIO extension page once and let it finish installing PlatformIO Core.

4. Confirm The PlatformIO Configuration

Open platformio.ini. The important target settings are:

[env:m5stack-cores3-lite]
platform = espressif32
board = m5stack-cores3
framework = arduino
board_build.flash_size = 16MB
board_build.partitions = default_16MB.csv
board_build.arduino.memory_type = qio_qspi

The environment name is m5stack-cores3-lite. The board definition is m5stack-cores3 because PlatformIO uses the standard CoreS3 board profile for this hardware family.

Expected: You do not need to manually install each Arduino library. PlatformIO reads lib_deps and downloads the required libraries during the first build.

5. Build The Firmware

Open a VS Code terminal and run:

cd "C:\Users\pjros\Documents\Codex\2026-06-05\technical-implementation-prompt-premium-air-quality\outputs\air_quality_station"
$env:PYTHONIOENCODING='utf-8'
$env:PYTHONUTF8='1'
pio run
Expected: The build ends with [SUCCESS]. The final verification run for this repo completed successfully with about 35.8% RAM and 22.0% flash used.

The UTF-8 environment variables avoid a Windows console encoding issue that can happen while PlatformIO prints dependency information.

6. Connect And Upload To The CoreS3-Lite

  1. Plug the CoreS3-Lite into USB.
  2. Use a USB-C data cable.
  3. Wait a few seconds for Windows to detect the board.

Find The Serial Port

pio device list
Expected: You should see a COM port, such as COM5. The number may be different on your PC.

Upload Automatically

pio run --target upload

Upload To A Specific Port

If PlatformIO cannot choose the port automatically, replace COM5 with the port from pio device list:

pio run --target upload --upload-port COM5
Expected: Upload output should include Hash of data verified, Leaving..., and [SUCCESS].
If upload gets stuck at connecting: hold the CoreS3 boot/download button while PlatformIO says Connecting..., then release when flashing starts.

7. Open The Serial Monitor

After upload, open the monitor:

pio device monitor

Or specify the port:

pio device monitor --port COM5
Expected: The monitor uses 115200 baud from platformio.ini. Press Ctrl+C to exit.

8. Prepare The microSD Card

  1. Format the microSD card as FAT32.
  2. Insert it into the CoreS3-Lite.
  3. Boot the device.

On first boot, the firmware creates:

/config.json
/log/
/cam/
Expected: The maintenance screen should report that SD is mounted. The web dashboard and FTP can also be used to inspect files later.

9. Configure Wi-Fi

Edit /config.json on the SD card and set your network name and password:

{
  "wifi_ssid": "YourNetworkName",
  "wifi_password": "YourPassword",
  "timezone": "CST6CDT,M3.2.0,M11.1.0",
  "alarm_hysteresis_percent": 5.0
}

You do not need to remove the other config fields. This snippet only shows the fields most people edit first.

Expected: After reboot, the maintenance screen should show Connected: yes, an IP address, subnet, gateway, and RSSI.

10. Open The Device Web Dashboard

Once Wi-Fi is connected, open one of these from a phone or desktop on the same network:

http://core-air.local/
http://<device-ip>/

The dashboard shows live readings, charts, file downloads, camera images, and config.json download/upload.

Expected: The dashboard should show Wi-Fi status, MQTT status, SD status, current firmware state, IP address, and live SEN66 readings once the sensor has warmed up.
Security note: The dashboard is for trusted local networks. Do not port-forward it to the public internet.

Troubleshooting

No COM Port Appears

  • Try another USB-C cable.
  • Try another USB port.
  • Disconnect and reconnect the CoreS3-Lite.
  • Run pio device list again.

Build Fails While Downloading Packages

  • Check DNS and internet access.
  • Run pio run again after the connection is fixed.
  • If package folders are half-created, run pio run --target clean and then pio run.

Upload Fails At Connecting

  • Hold the boot/download button during the Connecting... message.
  • Release when flashing begins.
  • Try a lower upload speed by changing upload_speed in platformio.ini if needed.

Device Boots But Wi-Fi Does Not Connect

  • Check wifi_ssid and wifi_password in /config.json.
  • Make sure the network is 2.4 GHz or compatible with ESP32-S3 Wi-Fi.
  • Use the maintenance screen to check connection state and IP address.

SEN66 Does Not Report Data

  • Confirm SDA is GPIO 2 and SCL is GPIO 1.
  • Confirm the Adafruit breakout is powered from Grove 5 V and regulating to 3.3 V for the SEN66.
  • Allow the SEN66 warmup period. Stable readings can take a couple minutes after startup.
  • Check the maintenance screen for SEN66 errors and sample counters.

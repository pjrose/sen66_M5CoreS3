# Printable Enclosure

Use **[enclosure_v3](enclosure_v3/README.md)**: compact 108 x 76 mm vented box,
centered devices, rounded openings, positive end stops, continuous labeled
bezel, four countersunk M3 front screws and a four-insert M2.5 adapter mesa.
Three high, aligned wall keyholes offer one-screw or symmetric two-screw mounting.

Earlier design studies are retained locally, not included in this publication.
Do not mix parts between revisions. Download the complete v3 bundle from the
[enclosure release](https://github.com/pjrose/sen66_M5CoreS3/releases/tag/enclosure-v3).

The current design has passed CAD checks, but still needs a first test print
and physical fit/thermal verification. See the v3 assembly checklist before
printing or installing electronics.
